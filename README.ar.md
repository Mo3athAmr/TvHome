# TvHome — واجهة ذكية عربية لشاشات Android TV

> 🇬🇧 English: [README.md](README.md) · 📖 الدليل المصوّر: [docs/guide.html](docs/guide.html) · 🤖 التثبيت بوكيل ذكاء اصطناعي: [install.md](install.md)

**TvHome** يستبدل الواجهة الرئيسية لشاشة Android TV / Google TV بنظام عربي متكامل من اليمين لليسار:
شاشة رئيسية أنيقة بمحتوى يتجدد، و**رفيق** (مساعد صوتي ذكي يتحكم بالشاشة فعلاً)، ومواقيت الصلاة مع الأذان
وقفل الشاشة وقت الصلاة، ووضع الجمعة مع سورة الكهف، ومباريات مباشرة مع تذكير، وشاشة توقف بمواقيت الصلاة،
وأدوات على مستوى النظام. مكتوب بـ Kotlin و Jetpack Compose ومضبوط للشاشات قليلة الذاكرة (1.8 جيجا).

## المزايا

| القسم | وش يسوي |
|---|---|
| **الشاشة الرئيسية** | قسم كبير بأحدث مقاطع قنواتك في يوتيوب أو أعمال TMDB، وصفوف: جديد يوتيوب، المباريات، **أحدث الأفلام** و**أحدث المسلسلات** (تتجدد كل ١٥ دقيقة وعند الرجوع للرئيسية، وتظهر حلقات اليوم والأنمي بعبارة «الموسم · الحلقة · اليوم»)، والأكثر شيوعاً، وتطبيقاتك. |
| **المساعد رفيق** | اضغط زر المساعد أو المايك في الريموت وتكلم. جوجل يسمع (مايك الريموت ما يوصل إلا لجوجل) وواجهته مخفية، ورفيق يرد باللهجة السعودية كتابة وصوت. المزوّدات: Anthropic Claude ثم Experiential Labs ثم Gemini، مع انتقال تلقائي عند أي عطل. |
| **قدرات رفيق** | يبحث في مكتبة ضخمة للأفلام والمسلسلات والأنمي حسب التصنيف والبلد (كوري، ياباني، أنمي، آسيوي، تركي، عربي، خليجي…) والفترة والتقييم أو «شي يشبه عمل معيّن» ويعرضها بوسترات · فلتر عائلي و«بدون لقطات» في كل اقتراح · يفتح صفحة أي عمل · يشغّل أي فيلم أو حلقة في **ستريميو** («آخر حلقة»، «الموسم ٢ الحلقة ٥»…) ويختار بث 1080p سليم تلقائياً · يوتيوب: آخر مقطع لقناة، آخر حلقة من **برنامج** في قناة، القنوات المباشرة، البحث والتشغيل · القرآن · المباريات وفتح المباراة في كاسبر فليكس · الطقس · مواقيت الصلاة · الصوت والتشغيل والتنقل · قراءة الشاشة («وش هذا؟») · البحث في الإنترنت. الأوامر السريعة (الصوت، فتح تطبيق، الوقت…) تنفّذ خلال ٠٫٣ ثانية بدون ذكاء اصطناعي. |
| **الصلاة** | مواقيت أم القرى (الخبر افتراضياً ويمكن تغييرها)، صوت الأذان، **قفل الشاشة** من الأذان حتى الإقامة (مدة إقامة لكل صلاة)، خروج طارئ بضغط مطوّل على رجوع ٥ ثوانٍ، ووضع الاستعداد اختيارياً. |
| **الجمعة** | قفل وقت صلاة الجمعة، وسورة الكهف في الواجهة يوم الجمعة بثلاثة قرّاء (العفاسي، المعيقلي، السديس). |
| **المباريات** | المواعيد والنتائج المباشرة (ESPN / FilGoal / FotMob)، البطولات والأندية المتابعة، تحديث كل ١٥ ثانية أثناء اللعب، صفحة مباراة بالتشكيلات، تذكير قبل مباريات أنديتك (١٥/٣٠/٦٠ دقيقة)، وزر **شاهد في كاسبر فليكس** يفتح القناة مباشرة. |
| **شاشة التوقف** | لوحة مواقيت الصلاة فوق فيديو أو صور مع الطقس وبطاقة متبدلة، أو فيديوهات Aerial. |
| **أدوات النظام** | مركز التحكم (ضغط مطوّل على Home)، مبدّل التطبيقات (ضغطتين على Home)، الإشعارات، فحص الميزات مع زر إصلاح، البحث بلوحة مفاتيح وصفحات الأعمال (الإعلان، ستريميو). |
| **خفيف على الشاشة** | تفريغ الصور عند ضغط الذاكرة، كاش على القرص، قراءة الشاشة عند الحاجة فقط، والتقطيع حوالي ٢٪ على شاشة TCL بذاكرة 1.8 جيجا. |

## المتطلبات

| العنصر | ملاحظة |
|---|---|
| الشاشة | Android TV / Google TV بإصدار 8.0 أو أحدث. طُوّر على TCL Google TV (Android 12، ذاكرة 1.8 جيجا). |
| الكمبيوتر | ماك أو لينكس أو ويندوز مع **JDK 21** و **Android SDK** (المنصة 36 وأدوات البناء) و **adb** |
| TMDB | رمز «API Read Access Token» مجاني من <https://www.themoviedb.org/settings/api> (مطلوب) |
| مفاتيح الذكاء الاصطناعي | واحد على الأقل: Anthropic أو Experiential Labs أو Google Gemini (لرفيق فقط) |
| تطبيقات اختيارية | ستريميو (بإضافاتك)، كاسبر فليكس، يوتيوب |

## التثبيت

أسهل طريقة: افتح هذا المجلد في وكيل برمجة ذكي (Claude Code أو Cursor أو Codex…) وقل له
**«اتبع install.md»**، وهو يسألك وش تحتاج ويسوي كل الخطوات معك. أو يدوياً:

### ١ · الإعداد

```bash
cp local.properties.example local.properties   # عبّي sdk.dir و TMDB_READ_TOKEN ومفتاح المساعد
```

مدينة الصلاة: `app/src/main/java/com/moath/tvhome/prayer/PrayerTimes.kt` (`PrayerConfig`)،
مدن الطقس: `dashboard/DashboardData.kt` (`CITIES`)، ومدينة المساعد في تعليماته داخل `assistant/AssistantEngine.kt`.

### ٢ · البناء

```bash
./gradlew :app:testReleaseUnitTest :app:assembleRelease
# الناتج: app/build/outputs/apk/release/app-release.apk
```

ثبّت نسخة **release** دائماً لأنها أسرع بكثير على الشاشة. إذا الكمبيوتر مشغول:
`nice -n 19 ./gradlew --no-daemon --max-workers=1 …`

### ٣ · التثبيت على الشاشة

في الشاشة: *الإعدادات ← النظام ← حول ← اضغط «Build» سبع مرات*، ثم *خيارات المطوّر ← تصحيح USB*
(و«التصحيح عبر الشبكة» إن وُجد). عنوان IP الشاشة من *الإعدادات ← الشبكة*.

```bash
adb connect <ip-الشاشة>:5555                   # وافق على الرسالة في الشاشة
adb install -r app/build/outputs/apk/release/app-release.apk
TV=<ip-الشاشة>:5555 ./scripts/after-install.sh  # الصلاحيات وخدمة النظام (بعد كل تحديث)
TV=<ip-الشاشة>:5555 ./scripts/set-home.sh       # يخلي TvHome الواجهة الرئيسية + شاشة التوقف
```

### ٤ · اختياري

```bash
# قنوات «جديد يوتيوب»: معرّف قناة أو @معرّف في كل سطر، أو ملف subscriptions.csv من Google Takeout
adb push youtube_channels.txt /sdcard/Android/data/com.moath.tvhome/files/
# ضبط الساعة بعد انقطاع الكهرباء
adb shell settings put global ntp_server 162.159.200.123
```

- **ضبط قناة كاسبر واختيار بث ستريميو** يضغطان أزراراً عبر adb الداخلي للشاشة (127.0.0.1:5555).
  أول مرة تسألك الشاشة «السماح بالتصحيح؟» — اختر *السماح دائماً*.
- **تعطيل التطبيقات المثبّتة مسبقاً** لا يتم أبداً بدون موافقة صاحب الشاشة، وبأمر `pm disable-user --user 0` فقط
  (قابل للإرجاع)، وكل تطبيق معطّل يُسجّل في `scripts/disabled-packages.txt`.

### إرجاع كل شيء

```bash
TV=<ip-الشاشة>:5555 ./scripts/restore.sh        # أضف --uninstall لحذف TvHome أيضاً
```

## الريموت

| الزر | الوظيفة |
|---|---|
| المساعد / المايك | رفيق يسمع (عبر جوجل) ويرد |
| Home (ضغط مطوّل) | مركز التحكم |
| Home (ضغطتين) | مبدّل التطبيقات |
| رجوع (ضغط ٥ ثوانٍ) في قفل الصلاة | خروج طارئ (يظهر الشريط بعد ثانيتين) |
| OK على شاشة التوقف | إغلاقها |

## حل المشاكل

| المشكلة | الحل |
|---|---|
| مركز التحكم أو رفيق ما يستجيب بعد التحديث | شغّل `scripts/after-install.sh` مرة ثانية (شاشات TCL تمنع الخدمة حتى يُسمح لها بـ `APP_AUTO_START`). |
| `adb: No route to host` والشاشة شغالة | `adb kill-server && adb start-server && adb connect <ip>:5555` |
| رفيق يقول يحتاج مفتاح | أضف المفتاح في `local.properties` وأعد البناء. |
| بطاقة الصلاة مخفية | الساعة غير مضبوطة (السنة أقل من 2025) — راجع نصيحة NTP. |
